# 奶了个蛙 v2

一款手机优先的原生网页分层三消游戏。棋子使用 `assets/` 中的 16 张透明底奶蛙 PNG，无卡框、底色或牌面文字。素材来自真实奶蛙图裁剪，另有少量图生图补图，均已抠成透明底。游戏无需构建步骤或外部依赖。

## 运行

直接用现代浏览器打开 `index.html` 即可。开局会预加载图片；加载失败时显示荷叶绿占位图。

## 牌型

按代码中的顺序，16 种牌型为：

1. `main-stance` 站姿招手
2. `thinking` 托腮思考
3. `pray-wings` 天使合掌
4. `shocked` 抱头震惊
5. `monk` 和尚合掌
6. `belly-hold-a` 抱肚站立
7. `profile-stand` 侧面站
8. `laugh-headback` 仰头大笑
9. `santa-lie` 圣诞躺笑
10. `point-laugh` 指人笑
11. `peace-tongue` 比耶吐舌
12. `running` 跑步
13. `dancing` 跳舞
14. `sleeping` 睡觉
15. `chef` 厨师服
16. `superhero` 超人披风

每种图片的文件名为 `assets/<id>.png`。中文名仅用于无障碍说明和图片加载失败时的占位图。

## 玩法

- 点选没有被上层牌压住的奶蛙，送入下方 7 格荷叶槽位。
- 同类型奶蛙会在槽内聚拢，凑齐 3 张立即消除。
- 槽位装满 7 张且没有消除就失败；棋盘、槽位与暂存区全部清空才胜利。
- 每局「撤销」「洗牌」「移出」各能使用一次。撤销回退最近一步操作；洗牌重新分配棋盘牌型并提供新解序；移出将槽内前 3 张放到暂存区，点暂存牌可送回槽位。
- 顶部可切换第 1/2 关，也可重新开始本关。

第 1 关取前 8 种、每种 3 张，共 24 张；第 2 关用全部 16 种、每种 6 张，共 96 张。

## 有解构造

先将每种牌按三张一组组成解序，再打乱组的顺序。按解序逆序赋予严格递增的层高，因此在取一张牌时，所有可能压住它的牌已先被取走。每组三张连续进槽即消除，按完整解序游玩时槽内最多暂留两张。

## 测试

在当前目录执行：

```sh
node tests.mjs
```

测试覆盖 16 种牌型与素材文件、两个关卡的张数及每种类型计数、种子复现、25 个第 2 关种子的解序、遮挡、三消、判负、撤销、洗牌和移出。
