# 奶了个蛙 v6

一款手机优先的原生网页分层三消游戏。棋子使用 `assets/` 中的 16 张透明底奶蛙 PNG，呈现在暖白卡面上。素材来自真实奶蛙图裁剪，另有少量图生图补图，均已抠成透明底。游戏无需构建步骤或外部依赖。

## 运行

直接用现代浏览器打开 `index.html` 即可。开局会预加载图片；加载失败时显示荷叶绿占位图。

## 牌型

按代码中的顺序，16 种牌型为：

1. `main-stance` 站姿招手
2. `thinking` 托腮思考
3. `pray-wings` 天使合掌
4. `shocked` 抱头震惊
5. `monk` 和尚合掌
6. `belly-hold-a` 抱肚站立
7. `profile-stand` 侧面站
8. `laugh-headback` 仰头大笑
9. `santa-lie` 圣诞躺笑
10. `point-laugh` 指人笑
11. `peace-tongue` 比耶吐舌
12. `running` 跑步
13. `dancing` 跳舞
14. `sleeping` 睡觉
15. `chef` 厨师服
16. `superhero` 超人披风

每种图片的文件名为 `assets/<id>.png`。中文名仅用于无障碍说明和图片加载失败时的占位图。

## 玩法

- 点选没有被上层牌压住的奶蛙，送入下方 7 格荷叶槽位。
- 同类型奶蛙会在槽内聚拢，凑齐 3 张立即消除。
- 槽位装满 7 张且没有消除就失败；棋盘、槽位与暂存区全部清空才胜利。
- 每局「撤销」「洗牌」「移出」各能使用一次。撤销回退最近一步操作；洗牌重新分配棋盘牌型并提供新解序；移出将槽内前 3 张放到暂存区，点暂存牌可送回槽位。
- 顶部可切换第 1/2 关，也可重新开始本关。

第 1 关取前 8 种、每种 3 张，共 24 张；第 2 关是招牌难关，用全部 16 种、每种 9 张，共 144 张。

## 有解构造

第 1 关先将每种牌按三张一组组成解序，再打乱组的顺序。每组三张连续进槽即消除，按完整解序游玩时槽内最多暂留两张。

第 2 关采用波次交错解序：每波随机选 2～3 种牌，先交错发出每种的前两张，再发第三张。按解序游玩时，槽位会在消除前承受约 4～6 张牌的压力。生成后还会用游戏自身的解序模拟验收，确保返回的牌局有解。两关都按解序逆序赋予层高，因此按解序取牌时不会被上层牌挡住。

## v4 布局与界面

第 2 关的双堆中心移至横向 0.26 和 0.66，抽堆概率仍为 0.56/0.44；横向散布系数为 0.24，纵向以 0.42 为中心、散布系数为 0.30，坐标范围放宽至 x 0.01～0.83、y 0.01～0.82。第 1 关布局、棋子尺寸与玩法规则保持原样。

按种子 1～20、游戏的矩形遮挡判定统计，开局被压住张数均值由 141.4/144 降至 **138.1/144**，重叠对均值由约 4648 对降至 **2149.6 对**。重叠对低于 3000 的目标，但被压住张数尚未达到 132/144 的目标；上述指定散布参数仍会让大部分牌被上层牌覆盖。

界面改用奶蛙品牌图标、剩余张数徽标和底部悬浮坞；柔化棋子投影与棋盘装饰，提高槽位和道具触控高度，统一间距与圆角，并为减少动态效果的系统设置关闭脉冲和过渡。

## v6 一页布局与音乐

界面使用全屏弹性布局，顶栏、棋盘、暂存区、七格槽位与道具在一页内显示。棋盘根据容器宽高选择可用的最大尺寸，使用 `width: min(100cqw, 95.2cqh)` 和 `aspect-ratio: 1/1.05` 保持原有比例；旧浏览器使用视口高度估算尺寸作为回退。背景和面板改为更简洁的绿白表面。

顶栏「音乐」按钮控制程序化 WebAudio 背景音乐，默认开启，选择保存在本机 `localStorage`。首次点击或按键后才开始播放；切到后台会暂停，回到前台且开关仍开启时恢复。音乐使用 92 BPM 的固定八小节 C 大调五声音阶乐句、每小节一个低音音符，无外部音频文件。
